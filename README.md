Kehitämme tässä organisaatiossa sivuston julkaisutyökaluja. Pikakasinot.fi on staattinen sivusto: sisältö on JSON-tiedostoina, Python-rakennin kokoaa niistä HTML-sivut ja GitHub Actions julkaisee muutokset. Työkalujen lähdekoodi on yksityinen.
